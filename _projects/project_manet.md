Mobile Ad Hoc Networks (MANETs) operate without fixed infrastructure — each node acts as both host and router in a continuously changing topology. This makes them invaluable for military, emergency response, and IoT scenarios, but also uniquely vulnerable to attack.

This project investigates the full attack-defense lifecycle in ad hoc routing protocols:

**Attack analysis:**
- Blackhole and wormhole routing attacks
- Sybil identity spoofing
- Denial-of-service via resource exhaustion
- Byzantine fault injection

**Defense mechanisms:**
- Trust-based routing protocols
- Lightweight cryptographic authentication suited to resource-constrained nodes
- Anomaly detection adapted to highly dynamic topologies

Our work bridges theoretical security analysis with practical protocol design, producing solutions that balance security guarantees against the strict energy and bandwidth constraints of mobile ad hoc environments.
