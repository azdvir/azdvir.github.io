Agentic AI systems — where multiple autonomous agents collaborate over networks — introduce a fundamentally new attack surface. This project develops cryptographic attestation for agent identity, anomaly detection on agent communication patterns, and sandboxing frameworks for agentic systems deployed in sensitive environments such as healthcare and critical infrastructure.
